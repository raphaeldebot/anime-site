# Stack recommandée

## Frontend
- **Next.js** : framework principal pour le site, l’app, le SEO et les pages dynamiques
- **TypeScript** : code plus propre, fiable et maintenable
- **Tailwind CSS** : styling rapide et moderne
- **shadcn/ui** : composants UI propres et personnalisables

## Backend
- **Next.js Route Handlers / Server Actions** : backend intégré au projet
- **Better Auth** : gestion des comptes, sessions et connexion

## Base de données
- **PostgreSQL** : base de données principale
- **Drizzle ORM** : gestion de la base avec bon contrôle et structure propre

## Paiement / monétisation
- **Stripe** : abonnements, paiements et offres premium

## Fichiers / images
- **Cloudflare R2** : stockage des images, avatars et uploads

## Emails
- **Resend** : emails de connexion, vérification, reset password, notifications

## Qualité / tests
- **Playwright** : tests end-to-end

## Plus tard
- **Meilisearch** : recherche rapide pour posts, profils, forum, contenu

## Résumé
**Next.js + TypeScript + Tailwind + shadcn/ui + PostgreSQL + Drizzle + Better Auth + Stripe + Cloudflare R2 + Resend + Playwright**
